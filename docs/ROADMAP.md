# Roadmap

끝난 항목은 지운다. Phase 2까지가 1차 완성이다.

## Phase 1 — 테스트넷 지갑 (Polygon Amoy)

마쳤다. Amoy에서 USDC·JPYC 송금·수신과 주요 화면을 iPhone으로 확인했다. 남은 확인은 아래 보충 테스트로 두고 Phase 2와 따로 틈틈이 본다.

## 보충 테스트

### 키와 서명

- [ ] 복구 문구 화면: 스크린샷이 찍히고, 사진 앱·iCloud 경고 문구가 보이며, 앱 전환기 미리보기가 흐린지
- [ ] 앱을 닫았다 열어도 pending 거래가 확정으로 바뀐다
- [ ] 가스 부족, RPC 끊김에서 서명 전에 막힌다
- [ ] Sepolia: ETH faucet으로 받아 같은 송금·수신 흐름

### 화면 (iPhone)

- [ ] Import(복구 문구 입력), 재설치: 앱 삭제 → 재설치 → "기존 지갑 계속 쓰기" 또는 Import로 복원
- [ ] Receive: 주소 복사, 다른 지갑 앱이 QR을 읽는지
- [ ] 보내기 입력: 영문 자판으로 열리는 "직접 입력", 붙여넣기, 지우기 길게 눌러 비우기, 큰 글씨
- [ ] QR 스캔 → 수신자 입력(카메라 권한 요청, 거부 뒤 설정 안내 화면 포함)
- [ ] History: 대기 중 앱을 닫았다 열면 이어서 확인, dropped 모양
- [ ] 거래 상세: 확정·대기 모양, 대기 중 확정되면 바뀌는지, 주소·hash 복사, 탐색기 링크
- [ ] 홈: 수수료 0회일 때 빨간 "수수료 부족", 큰 글씨·영어에서 수수료 한 줄
- [ ] 한국어·영어: 기기 언어 자동, 재시작 후 유지
- [ ] 개발용 빌드를 다시 만든 뒤 앱 이름·아이콘·스플래시
- [ ] 헨리 코인: 동작 줄이기에서는 바로 보이는지
- [ ] `src/platform` 경계 뒤 회귀: 붙여넣기·복사·공유·카메라 권한 설정 이동

## Phase 2 — Polygon 메인넷 소액

전환 전:

- [ ] 개발용 지갑은 새로 만든다(개인 메인 지갑과 분리), 복구 문구를 종이에 백업
- [ ] 로그·SQLite에 secret이 없는지 확인
- [ ] 지갑 삭제·복구 문구 보기 같은 위험한 동작을 홈에서 떼어 설정 화면으로 옮기고, 더 강한 확인을 둔다(지금 "개발용" 카드는 정식 빌드에서 사라진다)
- [ ] 거래소 출금 조건 확인(지원 네트워크, 최소 금액, 수수료, travel rule)

실사용(소액: POL 가스용, USDC 수십 달러 미만, JPYC 몇천 엔):

- [ ] POL 먼저 입금 → 잔액
- [ ] 거래소/JPYC EX/MetaMask → 앱 (USDC, JPYC)
- [ ] 앱 → MetaMask, MetaMask → 앱
- [ ] 수수료 표시, confirmation, QR, history, 재시작, 복원

## 전시 데모
